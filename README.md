# RPG Tracking

一个以 RPG 属性成长为核心的“个人成长追踪”小应用。用户通过日常副本（任务/活动）获得属性收益，形成可视化与正反馈的成长记录。

当前版本：`v3.0.0-beta`

## 功能概览
- 属性体系：支持分类与条目两级结构，条目包含基础值、权重与类型（累积/衰退）。
- 副本管理：主线副本模板与日常生活条目管理，支持归档与取消归档。
- 计时页：常驻计时与任务结算（胜利）入口，支持主线副本与日常生活记录；右上角可直达副本管理。
- 结算规则：评分转为 bonus，按时间计价或固定倍率计算收益；未达预期支持独立 bonus 设置。
- 统计页：常驻热力图（最新靠右/靠左）+ 范围高亮 + 范围内记录列表与总收益。
- 设置：热力图最新方向、统计页紧凑布局、未达预期 bonus 等选项，开发者调试注入。
- 多语言：中英文双语与统一的中文时间格式展示。

## 技术栈
- iOS / SwiftUI
- SwiftData（本地持久化）

## 本地运行
1. 使用 Xcode 打开 `RPG Tracking.xcodeproj`
2. 选择真机或模拟器运行
