# RPG Tracking

一个以 RPG 属性成长为核心的“个人成长追踪”小应用。用户通过日常副本（任务/活动）获得属性收益，形成可视化与正反馈的成长记录。

当前版本：`v1.1.1-beta`

## 功能概览
- 属性体系：支持分类与条目两级结构，条目包含基础值、权重与类型（累积/衰退）。
- 副本体系：支持主线模板与支线记录；记录包含评分、时长、奖励倍数等，且支持修改。
- 结算规则：评分转为 bonus，按时间计价或固定倍率计算收益。
- 统计页：常驻热力图（支持“最新靠右/靠左”）+ 时间范围联动高亮 + 范围内记录列表与总收益。
- 设置：热力图最新方向、统计页紧凑布局等外观选项。

## 技术栈
- iOS / SwiftUI
- SwiftData（本地持久化）

## 本地运行
1. 使用 Xcode 打开 `RPG Tracking.xcodeproj`
2. 选择真机或模拟器运行
